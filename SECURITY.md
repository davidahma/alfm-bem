# Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/davidahma/alfm-bem/security/advisories/new) for issues involving data exposure, dependency vulnerabilities, or unsafe behavior across tenants. Identify the version, entry point, and observed impact. Use synthetic case records in reports. The current standalone release is the supported version.

Experience records can contain embeddings, feedback, and optional traces. Keep production records out of public issues, examples, and benchmark submissions.
